GoWild seat-check bookmarklet

Live GoWild seat counts can't be fetched by a web page (browser cross-origin rules), but a bookmarklet runs on Frontier's own page where the data lives.

Desktop: drag the green button to your bookmarks bar. Phone: tap it to copy, then make a new bookmark and paste it as the URL (not the name).

🎯 GoWild seats

Then open any prefilled “check fares” link above and, on Frontier's results page, tap the bookmark — it overlays every flight's GoWild fare and seats remaining.

Why not a button here? A web page can't read Frontier's data across origins (browser security) — the bookmarklet runs on Frontier's page to get around that. On a computer, the local dashboard (node src/cli.js dashboard) has a real ↻ live seats button that fetches Frontier for you — no bookmarklet needed.
